# Мой пет-проект
Идея: Телегрм-бот для очередей в чате телеграм
Суть: Очереди в чате студентов сейчас создают только хаос. Цель проекта – систематизировать очереди, сделать их удобнее и понятнее
Стек: [Python / PostgreSQL / Redis / Docker]
Цель: научиться взаимодействовать с пользовавтелями через бота телеграм, использовать контейнеризацию Docker
