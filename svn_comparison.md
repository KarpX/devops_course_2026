1. В Git ветка — это просто текстовый файл весом в 41 байт, который содержит SHA-1 хэш коммита, на который он указывает. Ветка в SVN — это физическая копия директории внутри центрального репозитория

2. Нет, в SVN нельзя сделать коммит без доступа к сети.

3. SVN предпочтительнее Git в следующих сценариях:
- Работа с огромными бинарными файлами
- Необходимость жесткой блокировки
- Частичное скачивание
- Гранулярный контроль доступа
